# Crosspost

Две части в одной папке:
- **Приложение** (своё окно) — пока раздел «Тренды e6ai и e621», остальные разделы появляются по шагам.
- **Публикация из командной строки** — `cli/crosspost.py`, см. ниже.

## Приложение: быстрый старт (Windows)

1. Установите Python 3.11+ с python.org (галочка «Add Python to PATH»).
2. Дважды щёлкните **`Install.bat`** — поставит библиотеки (один раз).
3. Запускайте **`Crosspost.bat`** — откроется окно приложения.

Если окна нет (не встала библиотека pywebview), приложение откроется во вкладке браузера — работает так же.
Если что-то не запускается — откройте **`Crosspost-debug.bat`**: он покажет ошибку в окне консоли.

Данные приложения (выгрузки, расчёты, настройки) лежат в `%LOCALAPPDATA%\Crosspost`.

**Готовые файлы** — JPEG-превью, GIF и перекодированное/сжатое видео, которые делает программа, копируются в папку `Файлы` рядом с программой (подпапки «JPEG-превью», «GIF», «Видео»). Папку можно сменить в «Настройки → Пост → Готовые файлы»; программа эти файлы сама не удаляет.

**Обновления.** При запуске Crosspost проверяет, вышла ли новая версия (отключается в «Настройки → Общие → Обновления»). Кнопка «Скачать обновление» качает выпуск с GitHub и проверяет контрольную сумму; «Установить и перезапустить» заменяет файлы программы, сохраняя прежнюю версию для отката. Данные, `config.toml`, `tokens.json` и папка `Файлы` не затрагиваются.

Выпуск собирается командой `python tools/make_release.py` — она создаёт `dist/Crosspost-<версия>.zip` и `.zip.sha256`, их нужно приложить к выпуску на GitHub (тег `v<версия>`).

Структура: `app/` — приложение, `core/` и `platforms/` — общий код площадок, `cli/` — запуск из командной строки, `tests/` и `tools/` — проверки и установка.

### Тренды
1. В **Настройках** укажите ваш ник на e621/e6ai (сайты просят его в запросах программ) и теги «моего стиля».
2. В **Трендах** нажмите «Скачать выгрузку» для e6ai и для e621. Выгрузка e621 большая (порядка гигабайта) — первый раз займёт время, дальше обновляется сама по расписанию из настроек.
3. Если сайт не скачивается из приложения — скачайте файлы `posts-…csv.gz` и `tags-…csv.gz` с `e6ai.net/db_export/` или `e621.net/db_export/` вручную и нажмите «Подключить скачанные файлы».

Что показывает: популярное сейчас, растущие теги, прогноз на 4 недели с проверкой точности на истории, ниши (спрос против конкуренции), сезонные теги и опережающие сигналы (растёт на e621, на e6ai ещё нет).

### Прогноз и статистика поста
- **Статистика → «Что на картинке заходит лучше»**: теггер один раз размечает превью старых постов, и видно, какие темы поднимают охват, какие проседают и что давно не выходило.
- **Новый пост**: прогноз просмотров для каждого канала Telegram — разброс, шанс на хит, что прибавляет и убавляет, лучшее время на неделе.
- **История → «Статистика поста»**: просмотры, реакции, место среди постов канала, кривая набора просмотров и сравнение с прогнозом; для e6ai — score и избранное.
- Первые 7 дней фоновая отправка сама снимает цифры свежих постов (через 1, 3, 6, 12 ч, сутки…). Для этого нужен вход в Telegram через API; у фоновой отправки своя копия входа, которая удаляется при выходе из аккаунта.

# Публикация из командной строки — одна команда, шесть площадок

Публикует картинки с текстом в Discord, два Telegram-канала/группы, группу VK, X, DeviantArt и Reddit.
Перед отправкой картинки автоматически подгоняются под лимиты каждой площадки: если файл подходит, уходит оригинал, если нет — уменьшается или пережимается.

## Установка

1. Установите Python 3.11 или новее (python.org; на Windows отметьте «Add Python to PATH»).
2. В папке проекта выполните:
   ```
   pip install -r cli/requirements.txt
   ```
3. Скопируйте `config.example.toml` в `config.toml` и заполните ключи (инструкции ниже).
   Ненужную площадку можно выключить: `enabled = false`.

## Использование

```
python cli/crosspost.py art.png -t "Новый арт!" --title "Закат над морем" --tags sunset,digitalart
```

Скрипт покажет, что и куда отправит, и спросит подтверждение.

| Флаг | Что делает |
|---|---|
| `-t "текст"` | текст поста |
| `--text-file post.txt` | взять текст из файла (удобно для многострочного) |
| `--title "..."` | название работы; обязательно для DeviantArt (до 50 символов), заголовок поста на Reddit |
| `--tags a,b,c` | теги для DeviantArt |
| `--sfw` / `--nsfw` | обычный контент или 18+ (см. раздел ниже) |
| `--only telegram,discord` | только эти площадки |
| `--skip x` | все, кроме этих |
| `--dry-run` | ничего не публиковать, только показать план |
| `-y` | без вопроса «Опубликовать?» |

Несколько картинок: `python cli/crosspost.py 1.png 2.png 3.png -t "..."`. В Telegram, Discord и VK они уйдут одним постом-альбомом, в X — до 4 штук в одном твите, на Reddit — галереей, на DeviantArt — отдельными работами.

Если какая-то площадка не сработала, остальные всё равно опубликуются, а в конце скрипт подскажет команду для повтора только упавших.

## SFW и NSFW

У каждой площадки и у каждого отдельного канала, вебхука или сабреддита в `config.toml` есть `rating`:

| rating | что туда попадает |
|---|---|
| `"sfw"` | только обычный контент |
| `"nsfw"` | только 18+ |
| `"all"` | всё (по умолчанию) |

ВК по умолчанию стоит как `"sfw"`, туда 18+ не уйдёт никогда, даже если забыть указать rating.

При запуске укажите, какой это пост:

```
python cli/crosspost.py art.png -t "Новый арт" --sfw
python cli/crosspost.py spicy.png -t "Для взрослых" --nsfw
```

Если флаг забыт, скрипт спросит «Это контент 18+?», а не будет угадывать. С `-y` без флага он просто откажется работать. Это настраивается в `[general] require_rating`.

Перед подтверждением в плане видно, куда пост пойдёт и что пропущено по рейтингу, например:

```
Контент: NSFW (18+)
  – VK: пропуск — вся площадка (sfw)
  Telegram:
    пост: art.jpg 1000x1500, 0.3 МБ (лёгкая)
    оригиналы: art.png 2000x3000, 8.4 МБ (оригинал)
    куда: -1001234567890
    пропущено по рейтингу: @my_art_sfw (sfw)
    -1001234567890: оригиналы в комментарии
    18+: картинки под спойлером
```

Что дополнительно происходит при `--nsfw`:
- **DeviantArt** — работа помечается как Mature (уровень в `mature_level`).
- **Reddit** — пост помечается NSFW.
- **Telegram** — картинки под спойлером (`spoiler_nsfw`, включено по умолчанию).
- **Discord** — если включить `blur_nsfw = true`, картинки будут размыты до нажатия.
- **X** — у API нет пометки для отдельного поста. 18+ там можно постить, только если в настройках аккаунта включено «Помечать публикуемые медиафайлы как деликатные» (Настройки → Конфиденциальность и безопасность → Ваши публикации). Если это не включено, поставьте X `rating = "sfw"`.
- **Discord** — для NSFW-канала включите в настройках канала «Канал с возрастным ограничением».

## Настройка площадок

### Discord (2 минуты)
Настройки канала → **Интеграции** → **Вебхуки** → **Новый вебхук** → **Копировать URL вебхука**.
Вставьте URL в `webhook_urls`. Можно добавить несколько каналов, у каждого свой `rating`.

### Telegram (5 минут)
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен, вставьте в `bot_token`.
2. Добавьте бота **администратором** с правом публиковать сообщения: в оба канала, а также в группы обсуждения (если оригиналы идут в комментарии) и в группу с темами (если она есть).
3. Узнайте id: запустите `python cli/tg_ids.py`, опубликуйте что-нибудь в каналах и напишите в нужных темах группы — скрипт покажет id чатов и номера тем.
4. Заполните `channels` и, если нужно, `[telegram.group]`.

Пост всегда уходит **лёгким JPEG** (рецепт в разделе `[light]`: по умолчанию 50% размера, качество 88). **PNG-оригиналы** — по настройке `originals` у каждого канала:

| originals | куда идут оригиналы | что нужно |
|---|---|---|
| `"comments"` | файлами в комментарии к посту (старая схема) | у канала включены комментарии (привязана группа обсуждения), бот — админ в ней |
| `"reply"` | файлами ответом на пост прямо в канале (новая схема) | ничего, работает и без комментариев |
| `"none"` | не отправляются | — |

Оригиналы уходят без подписи и без уведомления подписчикам (`silent_originals`). Бот может загрузить файл до 50 МБ: PNG крупнее скрипт попробует пережать без потерь, а если не выйдет — предупредит и пропустит этот файл.

Как работает режим `"comments"`: бот публикует пост в канал, Telegram сам пересылает его в группу обсуждения, бот ждёт эту копию (до `comments_wait_seconds`) и отвечает на неё файлами — они появляются в комментариях. Для этого бот читает обновления через `getUpdates`: **не используйте этот же токен для другого бота**, и у бота не должен быть включён webhook.

**Пересылка в группу с темами.** Если заполнен `[telegram.group]`, после публикации пост пересылается в группу: SFW — из SFW-канала в `sfw_topic`, 18+ — из 18+ канала в `nsfw_topic`. Оригиналы в группу не пересылаются. Спойлер у 18+ сохраняется только если он был на исходном посте, поэтому `spoiler_nsfw = true`. В канале не должен быть включён запрет копирования — иначе Telegram не даст переслать.

Обе схемы можно смешивать: например, у SFW-канала `"comments"`, у 18+ канала `"reply"`.

Если пост вышел, а оригиналы или пересылка в группу не удались (например, копия поста не появилась в обсуждении вовремя), Telegram считается опубликованным: в отчёте будет строка с ⚠ и подсказкой, что добавить вручную. Повторять `--only telegram` в этом случае не нужно — получится дубль поста.

### VK (10 минут)
Фото на стену группы ВК разрешает загружать только с токеном пользователя (администратора группы), токен сообщества не подойдёт.
1. Зайдите на [id.vk.com/about/business](https://id.vk.com/about/business/go) и создайте приложение типа **Веб**.
2. В настройках приложения добавьте доверенный Redirect URL: `http://localhost:8765/callback`, а базовый домен — `localhost`.
3. Скопируйте ID приложения в `app_id`, числовой id группы — в `group_id` (виден в адресе группы или в «Управление → Адрес»).
4. Выполните `python cli/auth.py vk` — откроется браузер, разрешите доступ. Токен сохранится в `tokens.json` и будет обновляться сам.

Если ВК не принимает localhost, укажите в приложении и в `redirect_uri` любой свой сайт и запустите `python cli/auth.py vk --manual`: после входа скопируйте адрес из браузера в консоль.

### X / Twitter (10 минут, платно)
API X работает по оплате за использование: примерно **$0.015 за пост**, с картинкой около $0.02, а пост **со ссылкой — около $0.20**. Поэтому скрипт по умолчанию вырезает ссылки из текста для X (`allow_links = false`). Цены меняются — проверяйте в консоли разработчика.
1. Зарегистрируйтесь на [developer.x.com](https://developer.x.com), пополните баланс.
2. В приложении: **User authentication settings** → права **Read and Write**.
3. **Keys and tokens**: скопируйте API Key/Secret и сгенерируйте Access Token/Secret (после смены прав — перегенерируйте). Вставьте все четыре значения в `[x]`.

### DeviantArt (5 минут)
1. [deviantart.com/developers](https://www.deviantart.com/developers/) → **Register your Application**.
2. В **OAuth2 Redirect URI Whitelist** добавьте `http://localhost:8765/callback`.
3. Скопируйте `client_id` и `client_secret` в `[deviantart]`.
4. Выполните `python cli/auth.py deviantart` и разрешите доступ в браузере.

Токен обновляется автоматически. Если вы долго (около 3 месяцев) не постили, просто запустите `cli/auth.py deviantart` ещё раз.

По умолчанию работы публикуются с `noai = true` (запрет на обучение ИИ) и `is_ai_generated = false` — поменяйте в конфиге, если нужно.

### Reddit (заявка на доступ + 5 минут)
С ноября 2025 года Reddit не выдаёт доступ к API автоматически: даже для личного скрипта нужно подать заявку и дождаться одобрения (это называется Responsible Builder Policy). Проверка ручная и может занять несколько недель. Поэтому в конфиге Reddit по умолчанию выключен.
1. Войдите в аккаунт, с которого будете постить, и откройте [reddit.com/prefs/apps](https://www.reddit.com/prefs/apps).
2. Создайте приложение типа **script**, redirect uri — `http://localhost:8765/callback`.
3. Если Reddit попросит заявку, заполните её по ссылке из той же страницы или из [r/redditdev](https://www.reddit.com/r/redditdev/). Честно опишите задачу: «личный скрипт, публикую свои рисунки в свой профиль и несколько сабреддитов, без сбора данных».
4. После одобрения впишите в `[reddit]` client_id (строка под названием приложения), secret, логин и пароль и поставьте `enabled = true`.

Если на аккаунте включена двухфакторная авторизация, вход по паролю через API не пройдёт. Проще всего завести отдельный аккаунт для публикаций или временно отключить 2FA.

Сабреддиты перечисляются в конфиге блоками `[[reddit.subreddits]]`, у каждого свой `rating`. Свой профиль указывается как `u_ваш_логин`.

Перед тем как добавлять сабреддит, прочитайте его правила. Во многих обязателен флэр (`flair_id`), а самопиар ограничен. За одинаковые посты сразу во много сабреддитов Reddit может посчитать аккаунт спамерским. Скрипт делает паузу между сабреддитами, но лучше держать список коротким.

Текст поста по умолчанию публикуется первым комментарием (`text_as_comment`). Заголовок берётся из `--title`, а если его нет — из первой строки текста.

## Безопасность
`config.toml` и `tokens.json` дают полный доступ к постингу от вашего имени. Не отправляйте их никому и не выкладывайте на GitHub (они уже в `.gitignore`).
