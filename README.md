# Crosspost

Программа для Windows для тех, кто публикует арт: один раз подготовили работу — и она уходит на все площадки сразу, а потом видно, что зашло лучше.

- **Кросспостинг:** Telegram, Discord, ВКонтакте, Bluesky, DeviantArt, e6ai / e621. Для каждой площадки картинка сама подгоняется под её лимиты, подписи и хэштеги настраиваются, посты можно планировать.
- **Умное таргетирование и перевод** (включаются в «Настройки → Функции»): версии одного поста (RU / EN / без надписей) для разных площадок и английский текст с автопереводом через DeepSeek.
- **Видео и GIF:** редактор (обрезка, рамка, поворот, зацикливание), перекодирование под лимиты площадок.
- **Статистика:** просмотры и реакции по каналам, индекс успеха, прогноз для нового поста, календарь публикаций.
- **Тренды и теги:** что набирает популярность на e6ai и e621, подбор тегов теггером по картинке.
- **Обновления по кнопке** с проверкой контрольной суммы и откатом.

Все ключи и данные хранятся только на вашем компьютере. Программа предназначена для совершеннолетних: она работает и с контентом 18+ (флаги SFW / NSFW задаются для каждого поста).

Скачать последнюю версию — в разделе [Releases](../../releases). Дальше читайте «быстрый старт».

## Приложение: быстрый старт (Windows)

1. Установите Python 3.11+ с python.org (галочка «Add Python to PATH»).
2. Дважды щёлкните **`Install.bat`** — создаст отдельное окружение `.venv` рядом с программой и установит библиотеки в него. Системные пакеты Python не меняются.
3. Запускайте **`Crosspost.bat`** — откроется окно приложения.

Если окна нет (не встала библиотека pywebview), приложение откроется во вкладке браузера — работает так же.
Если что-то не запускается — откройте **`Crosspost-debug.bat`**: он покажет ошибку в окне консоли.

Оба способа запуска используют `.venv`; если его ещё нет, сначала открывается установщик. При переходе со старой версии закройте приложение и фоновую отправку и запустите `Install.bat` один раз. Уже включённый автозапуск Windows будет переведён на новое окружение. Повторная установка использует существующий `.venv`; обновление приложения сохраняет его. Если вы перенесли папку программы или удалили/заменили базовый Python и запуск перестал работать, удалите только `.venv` и снова запустите `Install.bat`. Настройки и история хранятся отдельно и сохранятся.

Если установка оборвалась или проверка библиотек не прошла, следующий запуск снова предложит установку: наличие папки `.venv` само по себе не считается успешной установкой.

Данные приложения (выгрузки, расчёты, настройки) лежат в `%LOCALAPPDATA%\Crosspost`.

**Готовые файлы** — JPEG-превью, GIF и перекодированное/сжатое видео, которые делает программа, копируются в папку `Files` рядом с программой (подпапки `JPEG previews`, `GIF`, `Video`). Папку можно сменить в «Настройки → Файлы → Хранение файлов»; программа эти файлы сама не удаляет.

**Обновления.** При запуске Crosspost проверяет, вышла ли новая версия (отключается в «Настройки → Общие → Обновления»). Кнопка «Скачать обновление» качает выпуск с GitHub и проверяет контрольную сумму; «Установить и перезапустить» заменяет файлы программы, сохраняя прежнюю версию для отката. Данные, `config.toml`, `tokens.json` и папка `Файлы` не затрагиваются.

Структура: `app/` — приложение, `core/` и `platforms/` — общий код площадок, `tests/` и `tools/` — проверки и установка.

### Подготовка и восстановление публикаций

- **Журнал публикации** доступен на экране отправки и в карточке публикации в истории. Этапы сохраняются между запусками; секреты маскируются. Для старых публикаций подробного журнала может не быть.
- **Шаблоны публикации** находятся на экране нового поста. Они сохраняют текст, рейтинг, исключённые места, подписи, теги и параметры обработки. При применении добавленные файлы сохраняются, а глобальные настройки не меняются. Исключения каналов привязаны к их идентификаторам, а не порядку в списке.
- **Резервные копии** — «Настройки → Файлы → Резервные копии». Можно скачать ZIP-копию и добавить её из файла. Лимит данных одной копии — 8 ГБ. Оригиналы включаются отдельно; без них часть вложений после переноса потребуется добавить заново. Внешняя папка готовых файлов `Files`, модели и выгрузки трендов не включаются.
- **Восстановление** требует выключить фоновую отправку и дождаться завершения задач. Перед заменой автоматически сохраняется копия текущих данных. Изменения применяются после полного закрытия и повторного запуска приложения; очередь приостанавливается, запланированные посты требуют проверки и повторного назначения времени. При ошибке замены файлов выполняется откат.
- **Просмотр по площадкам** показывает итоговый текст с подписью, выбранные файлы, теги и предполагаемые преобразования. Оформление зависит от площадки; размер перекодированного файла определяется при обработке.
- **Проверка перед публикацией** отдельно проверяет файлы и ограничения, отдельно — доступ и права. Проверка доступа не публикует посты. Автоматически поддерживаются Bot API Telegram, вебхуки Discord и сессии Bluesky; для остальных способов входа результат отмечается как непроверенный и предлагается открыть настройки площадки.

В резервные копии не входят ключи, пароли, адреса вебхуков и сессии входа. Существующие учётные данные на этом компьютере при восстановлении сохраняются; при переносе на другой компьютер подключите площадки заново. Копия содержит личные посты и файлы: храните её в доверенном месте. Контрольные суммы обнаруживают повреждение, но не подтверждают происхождение чужого архива.

### Черновики, очередь и поиск

- **Коллекция черновиков** находится на экране нового поста. Сохраните пост под именем: после этого изменения сохраняются автоматически. Есть статусы «В работе» и «Готов», поиск, удаление и сохранение копии. Статус «Готов» — отметка автора; проверки перед отправкой всё равно выполняются. При переключении на другой черновик текущая работа сохраняется. Если документ изменён в другом окне, приложение предложит открыть сохранённую версию; локальные изменения можно сохранить отдельной копией.
- **Вложения сохранённых черновиков и текущего открытого поста не удаляются автоматической очисткой.** Отсутствующие файлы показываются явно: удалите их из поста или добавьте заново. Коллекция входит в резервную копию базы; сами оригиналы входят только при выборе соответствующего параметра.
- **Редактирование поста из очереди:** нажмите «Редактировать» в запланированных постах или конвейере. Этот пост приостанавливается до сохранения или отмены правок, в том числе после закрытия приложения. Можно менять текст, файлы и получателей, сохраняя ID и позицию в конвейере. Если прежнее время уже прошло, выберите новое; отмена правок не отправляет просроченный пост автоматически.
- **Свой текст для каждой площадки** включается в настройках нужной площадки переключателем «Отдельные заголовок и текст для этой площадки» (по умолчанию выключен). После включения в редакторе появляется отдельный блок: для каждого поста можно выбрать собственный текст вместо основного/английского; подпись и хэштеги добавляются как обычно. При отключении настройки общий вариант используется и для очереди, а отдельные тексты сохраняются в черновиках, очереди и шаблонах для повторного включения.
- **Alt-описания Bluesky** задаются отдельно для каждого вложения и сохраняются с постом. Пустое поле использует заголовок, если соответствующая настройка включена. В просмотре состава поста виден итоговый alt-текст.
- **Поиск истории** находится в режиме «Список» и работает по всей базе, включая записи старше первых 50. Доступны текст, название, имя файла, теги, площадка, общий результат публикации и диапазон дат, а также переход между страницами. Сортировка по индексу и фильтр хитов относятся к загруженной странице.
- **Предупреждение о повторе** сравнивает вложения с доступными изображениями и превью из истории приложения и импортированных постов. Проверку можно запустить вручную; перед новой отправкой или добавлением в очередь найденные совпадения требуют подтверждения. Похожие кадры могут быть разными работами, а отсутствующие превью нельзя проверить — это предупреждение, а не гарантия обнаружения всех повторов. Досылка к той же публикации не считается новым повтором. Автоматическая отправка уже принятого задания не требует нового подтверждения.

### Тренды
1. В **Настройках** укажите ваш ник на e621/e6ai (сайты просят его в запросах программ) и теги «моего стиля».
2. В **Трендах** нажмите «Скачать выгрузку» для e6ai и для e621. Выгрузка e621 большая (порядка гигабайта) — первый раз займёт время, дальше обновляется сама по расписанию из настроек.
3. Если сайт не скачивается из приложения — скачайте файлы `posts-…csv.gz` и `tags-…csv.gz` с `e6ai.net/db_export/` или `e621.net/db_export/` вручную и нажмите «Подключить скачанные файлы».

Что показывает: популярное сейчас, растущие теги, прогноз на 4 недели с проверкой точности на истории, ниши (спрос против конкуренции), сезонные теги и опережающие сигналы (растёт на e621, на e6ai ещё нет).

### Прогноз и статистика поста
- **Статистика → «Что на картинке заходит лучше»**: теггер один раз размечает превью старых постов, и видно, какие темы поднимают охват, какие проседают и что давно не выходило.
- **Новый пост**: прогноз просмотров для каждого канала Telegram — разброс, шанс на хит, что прибавляет и убавляет, лучшее время на неделе.
- **История → «Статистика поста»**: просмотры, реакции, место среди постов канала, кривая набора просмотров и сравнение с прогнозом; для e6ai — score и избранное.
- Первые 7 дней фоновая отправка сама снимает цифры свежих постов (через 1, 3, 6, 12 ч, сутки…). Для этого нужен вход в Telegram через API; у фоновой отправки своя копия входа, которая удаляется при выходе из аккаунта.

## Безопасность
Ключи и токены площадок хранятся в папке данных `%LOCALAPPDATA%\Crosspost` и дают полный доступ к постингу от вашего имени. Не отправляйте их никому и не выкладывайте на GitHub.

## Проверки для разработки

После установки `requirements-app.txt` запустите из корня репозитория:

```sh
python -m unittest discover -s tests -p "test_*.py" -v
```

Проверки используют временные данные и подмену отправки, не требуют аккаунтов и не публикуют посты. Они запускаются также в GitHub Actions на Windows и Linux с Python 3.11 и 3.12.

Если после отправки потерялся ответ площадки, приложение показывает «Возможно, опубликовано». Такой результат не повторяется автоматически: сначала проверьте площадку. Автоповтор конвейера применяется только при подтверждённом полном отказе; частично вышедшие посты автоматически не пересылаются.

### Устройство экранов и первый запуск

В разделе «Публикации» по умолчанию открыт календарь; альтернативный вид — список, выбор запоминается. Назначенные вручную посты и автоматическая очередь находятся в раскрываемой панели «Очередь» со счётчиком рядом с переключателем вида; новости и лидеры месяца — в статистике. При добавлении в приостановленную очередь приложение прямо сообщает, что отправка ещё не включена. Создание или возобновление задания сразу запускает фоновую отправку; до подтверждения её запуска интерфейс просит не закрывать окно.

Для новой установки дополнительные модули статистики, трендов, теггера и прогноза изначально выключены. Подключить их можно в «Настройки → Функции». Существующие настройки при обновлении сохраняются. На пустом экране предлагаются три шага к первой публикации; подсказку можно скрыть. Поиск настроек находит разделы по названию и ключевым словам. Дополнительные параметры соединения Telegram свёрнуты отдельно.

Отключение языков или таргетирования сохраняет переводы и метки внутри черновика. Оно влияет только на применение этих полей при публикации. Асинхронные расчёты привязаны к актуальному состоянию поста; устаревшие ответы не заменяют новые. Пользовательские названия помечены `translate="no"`, новые ключи интерфейса добавляются через `I18N.key`.

### Проверка и выпуск обновлений

Основные версии зависимостей зафиксированы в `requirements-constraints.txt`, который подключается из `requirements-app.txt`. Для NumPy на Python 3.11 выбран отдельный совместимый пин. Дополнительные зависимости теггера/GPU устанавливаются отдельно. Windows и Linux проверяются на Python 3.11 и 3.12.

Дополнительные проверки интерфейса:

```sh
node tests/web/post-state.test.js
python -m playwright install chromium
python tests/browser/test_workflows.py
```

Браузерные проверки используют временные данные и подменённый отправитель. При ошибке сохраняется скриншот в `test-artifacts/`; эта папка не попадает в архив выпуска. Для системного Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

Workflow выпуска ждёт успешного завершения матрицы Python и проверок интерфейса. Опубликованный архив автоматически не перезаписывается: каждому изменённому выпуску нужен новый номер в `app/__init__.py`, запись changelog и соответствующий тег. Переиздание под прежним номером не определяется встроенной проверкой версий как обновление.

### Путеводитель по настройкам

Кнопка «Быстрая настройка» в заголовке настроек открывает четыре шага: площадки, оформление поста, расписание и дополнительные функции. На первом шаге уже настроенные площадки отмечены автоматически. Выбор площадок задаёт маршрут путеводителя и сам по себе не отключает остальные аккаунты.

Переход к реальным полям сворачивает путеводитель в компактную полосу с кнопкой «Вернуться к шагам». Шаг и выбранные площадки сохраняются в `ui.json`; можно пропускать шаги, закрывать и открывать путеводитель повторно. «Начать сначала» сбрасывает только его прогресс, сохраняя настройки приложения. Необязательные функции включаются теми же переключателями, что и в обычных настройках.

Финальная проверка локальная: проверяет заполнение настроек выбранных площадок, не обращается к ним, не запускает очередь и не публикует пробные посты. Действительность сессии и права доступа проверяются на экране конкретной площадки. При изменении настроек результат проверки становится неактуальным.
