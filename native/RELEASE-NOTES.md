# CrossPost Native 0.1.0 — первый C#-прототип

Отдельное приложение для Windows x64 на C# / WPF, без Python и WebView2.

- Редактор текста и одного изображения JPEG/PNG, предпросмотр и автосохранение черновика.
- Telegram Bot API: отправка, история и редактирование текста/подписи.
- Деморежим без запросов и публикаций. Для реальной отправки нужны бот и канал.
- Токен защищается Windows DPAPI. Данные хранятся отдельно от Python-версии.
- Нет автоматических повторов при неизвестном результате отправки.

## Установка

Скачайте ZIP, распакуйте **все файлы** в отдельную папку и запустите `CrossPost.Native.exe`.
.NET отдельно устанавливать не нужно. Включён деморежим.

Это предварительный прототип: другие площадки, альбомы, теггер, расписание,
импорт истории и автоматическое обновление ещё не перенесены.

Сборка, 10 проверок поведения и запуск настоящего окна WPF проверяются на Windows в CI.
Реальная отправка в Telegram в CI не выполняется.
