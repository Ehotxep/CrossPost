# CrossPost Native 0.0.8-dev

- Переключатель Русский / Оба / English с отдельным выбором языка каждой площадки.
- Отдельные русские и английские заголовки/описания, включаемые для нужных площадок в настройках.
- Предпросмотр и лимиты по итоговому тексту, сохранение вариантов, фиксация языка и текста в очереди.
- Схема SQLite 5 с резервной копией и совместимостью прежних русских черновиков/заданий.
- Общая публикация в Telegram, Discord и Bluesky: выбор назначений, проверки всех лимитов, атомарная очередь, отдельные результаты и одна работа в календаре.
- Очередь и расписание работают после закрытия окна; подтверждённые отправки не повторяются при сбое другого назначения.
- Обновления из настроек: каналы нативных GitHub-релизов, проверка при запуске, скачивание с SHA-256 и манифестом, установка из ZIP.
- Отдельный обновлятор завершает активную отправку, сохраняет старую программу и базу, проверяет запуск новой версии и возвращает прежнюю при ошибке.
- Telegram: текст, фото/альбомы, редактирование. Discord: webhook, изображения, редактирование текста. Bluesky: ALT, рейтинги, ссылки и подготовка изображений.
- Импорт Python-истории, календарь, объединение и локальная статистика. Версионированная схема SQLite с резервными копиями.

Для обновления с 0.6 и ниже впервые распакуйте весь архив вручную: старые версии не содержат обновлятора.
Прототип Windows x64; самодостаточная поставка, Python и .NET отдельно не нужны. Подпись издателя отсутствует.
Настройки и история хранятся отдельно от Python. Сетевые адаптеры покрыты фиктивными HTTP-ответами; реальные отправки на пользовательских аккаунтах требуют ручной проверки.
