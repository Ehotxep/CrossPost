# Состояние проекта

Актуализировано: 2026-11-14. Этот файл описывает проверенное состояние, а не заменяет список задач.

## Активное направление

Python, ветка `experimental`. Версия исходников: `0.2.17`.
Проверенный выпуск перед текущим этапом: [0.2.17-experimental.16](https://github.com/Ehotxep/CrossPost/releases/tag/experimental-43585532107-1), коммит `892fd79`.
[CI выпуска](https://github.com/Ehotxep/CrossPost/actions/runs/43585532107) прошёл: Python 3.11/3.12 на Ubuntu и Windows, JavaScript и браузерные сценарии.
Последующие изменения в черновике не считаются опубликованными автоматически.

## Что вошло в экспериментальную сборку .16

- blep.art, e621 и floofgens.net разделены на независимые площадки в настройках и редакторе. Ключи, постоянные теги, базы тегов и тексты независимы; сохранена миграция старых настроек. e621 предназначен для допустимых правилами сайта работ, ИИ-арт туда не отправлять.
- Добавлен поиск по каталогу площадок; отключённые площадки можно скрывать из рабочего интерфейса.
- Тренды поддерживают floofgens.net, фильтрацию общих тегов, тематические группы и сравнение роста за месяц/квартал с указанием объёма данных.
- Для собственных booru-публикаций добавлены измерения через 24/72/168 часов и сравнение с предыдущими сопоставимыми публикациями. Поздний замер не подменяет пропущенный срок; недостаток данных показывается явно.
- Исправлены незакрытые SQLite-соединения в тестовых фикстурах на Windows и ожидание сетевой тишины при перезагрузке интерфейса трендов.

## Ограничения и незавершённое

- Скачивание живой выгрузки floofgens.net из облачной среды не подтверждено: сайт ответил HTTP 403. Ручной импорт и расчёты проверены на фикстурах.
- Reddit, JoyReactor и X остаются экспериментальными браузерными адаптерами. Проверки DOM-фикстур не подтверждают работоспособность актуального сайта или защит от автоматизации. Без отдельного запроса не проверять их на живых аккаунтах.
- Метрики описывают связи в наблюдаемых данных и не доказывают, что конкретный тег повышает успех арта. Полноценный рекомендатель творческих решений не реализован в этом этапе.
- C# / WPF развивается отдельно в `windows-native`. Данные о его готовности нужно проверять в `native/README.md` этой ветки; изменения Python не означают переноса функций в C#.
- Стабильный канал данным экспериментальным выпуском не изменялся. Не переносить туда функции автоматически.

## Текущий черновик

Первый этап улучшения достоверности прогноза Telegram: последовательные периоды проверки с недельным зазором, предшествующая норма канала, словарь признаков из обучающего периода, сравнение с обычным результатом канала. В статистике и редакторе показаны размер и период выборки, ошибки и ограничения. При недостатке проверочных постов численный прогноз отключён; слабая модель не предлагает лучшее время и вероятность хита.

Карточка параметров генерации, сравнение похожих работ и учёт независимых серий ещё не реализованы. Для них нужны отдельные этапы. Проверка прогноза ретроспективная, на текущих итогах базы; похожие работы в разных периодах пока не объединяются.

Локальные проверки этого этапа: 134 Python-теста (3 Windows-проверки пропущены на Linux), 12 JavaScript-тестов, 23 интерфейсных сценария; все завершились успешно. Дополнительно проверен синтаксис изменённых JavaScript-файлов. Результат CI нового выпуска — в [Experimental build](https://github.com/Ehotxep/CrossPost/actions/workflows/experimental.yml).

Пользователь разрешил публикацию этого этапа в экспериментальном канале. Точный номер готовой сборки и архив — в [Releases](https://github.com/Ehotxep/CrossPost/releases). Версия не менялась. Предыдущий этап правил Codex и диагностики опубликован в [0.2.17-experimental.17](https://github.com/Ehotxep/CrossPost/releases/tag/experimental-43586650759-1), коммит `14c6727`; его CI прошёл.
