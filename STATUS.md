# Состояние проекта

Актуализировано: 2026-11-16. Этот файл описывает проверенное состояние, а не заменяет список задач.

## Активное направление

Python, ветка `experimental`. Версия исходников: `0.2.17`.
Проверенный выпуск перед текущим этапом: [0.2.17-experimental.16](https://github.com/Ehotxep/CrossPost/releases/tag/experimental-43585532107-1), коммит `892fd79`.
[CI выпуска](https://github.com/Ehotxep/CrossPost/actions/runs/43585532107) прошёл: Python 3.11/3.12 на Ubuntu и Windows, JavaScript и браузерные сценарии.
Последующие изменения в черновике не считаются опубликованными автоматически.

## Что вошло в экспериментальную сборку .16

- blep.art, e621 и floofgens.net разделены на независимые площадки в настройках и редакторе. Ключи, постоянные теги, базы тегов и тексты независимы; сохранена миграция старых настроек. e621 предназначен для допустимых правилами сайта работ, ИИ-арт туда не отправлять.
- Добавлен поиск по каталогу площадок; отключённые площадки можно скрывать из рабочего интерфейса.
- Тренды поддерживают floofgens.net, фильтрацию общих тегов, тематические группы и сравнение роста за месяц/квартал с указанием объёма данных.
- Для собственных booru-публикаций добавлены измерения через 24/72/168 часов и сравнение с предыдущими сопоставимыми публикациями. Поздний замер не подменяет пропущенный срок; недостаток данных показывается явно.
- Исправлены незакрытые SQLite-соединения в тестовых фикстурах на Windows и ожидание сетевой тишины при перезагрузке интерфейса трендов.

## Ограничения и незавершённое

- Скачивание живой выгрузки floofgens.net из облачной среды не подтверждено: сайт ответил HTTP 403. Ручной импорт и расчёты проверены на фикстурах.
- Reddit, JoyReactor и X остаются экспериментальными браузерными адаптерами. Проверки DOM-фикстур не подтверждают работоспособность актуального сайта или защит от автоматизации. Без отдельного запроса не проверять их на живых аккаунтах.
- Метрики описывают связи в наблюдаемых данных и не доказывают, что конкретный тег повышает успех арта. Полноценный рекомендатель творческих решений не реализован в этом этапе.
- C# / WPF развивается отдельно в `windows-native`. Данные о его готовности нужно проверять в `native/README.md` этой ветки; изменения Python не означают переноса функций в C#.
- Стабильный канал данным экспериментальным выпуском не изменялся. Не переносить туда функции автоматически.

## Текущий черновик

Исправлен воспроизведённый сбой открытия «Трендов» (`reading length`): редактор и тренды использовали общее поле `fc` для разных форматов данных. Временной ряд темы перенесён в `trendForecast`; загрузка прогноза публикации его не меняет. Ответ выбора темы принимается только для актуальных источника, рейтинга и тега. Браузерный сценарий воспроизвёл ошибку до исправления и проверил разделение данных и повторные переходы между вкладками после исправления. Локально прошли все 23 интерфейсных сценария, 12 JavaScript-тестов и проверка синтаксиса изменённого JS.

Разбор обрыва загрузки оригинала на floofgens.net: по сообщению пользователя проверка аккаунта проходит, размер файла около 20 МБ. Старый журнал показывает только `ConnectionError`; конкретная причина соединения пока не установлена. Пользователь подтвердил ошибку и при ручной загрузке через сайт: форма сообщает «The upload could not be completed». Симптом не ограничивается CrossPost; точная причина на сервере или сетевом пути пока не установлена.

Добавлена безопасная диагностика вложенных транспортных ошибок (DNS/TLS/прокси/сброс, типы исключений и системные коды без сырых сообщений с URL или ключами). После потери ответа загрузки выполняется один read-only поиск точного MD5 на той же площадке. Только совпавший активный файл с корректным ID подтверждается как уже присутствующий; POST не повторяется. При ошибке поиска, отсутствии совпадения, удалённом посте или некорректном ответе сохраняется неизвестный результат. У найденного файла нужно проверить теги, описание и связь с родителем: поиск не доказывает, что изменения последнего запроса применились.

Оригиналы не сжимаются, лимиты размера сайта не предполагаются. Живой API из облачной среды проверить не удалось: CONNECT отклонён сетевым шлюзом среды с HTTP 403; это не ответ API floofgens.net. Тесты работают на подменённых ответах и не публикуют файлы. Локально прошли 141 Python-тест (3 Windows-проверки пропущены на Linux), включая 7 новых проверок сетевой диагностики и восстановления подтверждения; Результат CI выпуска — в [Experimental build](https://github.com/Ehotxep/CrossPost/actions/workflows/experimental.yml).

Предыдущий этап проверки прогноза опубликован в [0.2.17-experimental.18](https://github.com/Ehotxep/CrossPost/releases/tag/experimental-43589635130-1), коммит `240a309`; CI прошёл. Пользователь разрешил экспериментальный выпуск текущих исправлений для всех трёх booru-сайтов: e621, floofgens.net, blep.art. Точный номер сборки и архив — в [Releases](https://github.com/Ehotxep/CrossPost/releases); базовая версия не менялась.

## Следующий этап

При повторной проверке получить HTTP-статус или сетевую ошибку запроса загрузки из браузера; при необходимости сравнить с небольшим файлом. Не считать общий сбой формы доказанным лимитом размера или отказом всего сайта. Карточка генерации и сравнение похожих работ остаются отдельными этапами; перенос в C# ведётся отдельно в `windows-native`.
