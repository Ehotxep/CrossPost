# Изменения

## 0.1.0
- Окно «Вышла новая версия» при запуске (установить, напомнить позже, пропустить).
- Обновление по кнопке: скачивание выпуска с GitHub, проверка SHA-256, замена файлов с резервной копией и откатом (`app/selfupdate.py`, `app/apply_update.py`).
- `tools/make_release.py` собирает архив выпуска и файл контрольной суммы.
- Уведомление о новой версии (проверка выпусков на GitHub, «Настройки → Общие»).
- Редактор видео и GIF (обрезка, рамка, поворот, отражение, разрешение, зацикливание).
- Папка «Файлы» с готовыми JPEG-превью, GIF и видео; своя папка в настройках.
- Командная строка перенесена в `cli/`.
